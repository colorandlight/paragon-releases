# Paragon releases

Public **macOS downloads** for [Paragon](https://colorandlight.art) by Color+Light.

This repository does **not** contain application source. It exists so anyone can download a notarized build without access to the private codebase.

## Install

1. Open the latest [Release](https://github.com/colorandlight/paragon-releases/releases).
2. Download `Paragon-x.y.z.dmg`.
3. Open the disk image and drag **Paragon** into Applications.

The app is Developer ID signed and notarized. Licensing / purchase will be handled in the app later; the download itself is free.
