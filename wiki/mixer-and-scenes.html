Mixer and scenes

The mixer is where a show plays. Scenes are the programmed looks. Banks group controls. The dashboard is a grid of the parameters you want at hand.

Mixer

Open the Mixer from the View menu. The transport runs the active scene. Master controls cover level and speed for the show. Scene buttons select which scene is live.

Scenes

A scene is one programmed state: which animations run, on which fixtures, at what levels. The scene editor lists the animations in the scene and the parameters for the one you select.

Animations include the built-in library and script animations, which you edit as a script in the scene editor.

Dashboard

The dashboard is a small grid of knobs, buttons, and selectors pinned from show parameters. Empty slots stay blank. Use it for the controls you ride during a show, instead of hunting through the scene editor.
