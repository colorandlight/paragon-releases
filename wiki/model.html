The model

The model is the physical layout: zones, groups, and fixture instances. Open it with Model → Edit Model, or from the View menu.

Zones

A zone is a region of the installation, such as a staircase, a ceiling, or a room. The visualizer shows one zone at a time. Fixtures belong to a zone. Right-click a zone to create a fixture type, add a fixture, add a group, or delete the zone.

Use Add Zone at the bottom of the model list to make another zone.

Groups

A group is a folder of fixtures inside a zone. Use Add Group, then add fixtures into it. Groups are for organization. They are not a fixture type.

Fixture instances

An instance is one placed copy of a fixture type. The tree shows the type in brackets and the instance name after it, for example [MS_Railing_Strip] Handrail 4.

Right-click an instance for:

  • Duplicate Fixture — a copy of that instance, in the same place, with a new name.
  • Edit Fixture — open the type for project fixture types.
  • Render to Custom — turn that one instance into a new custom fixture. Paragon asks for a new type name. Other instances of the original type stay as they are.
  • Move to Zone — move the instance into another zone.
  • Delete — remove the instance. If the instance is used in an output mapping, delete that mapping first.

Deleting a fixture type

Deleting a type from the fixture library is separate from deleting an instance. If any instance of that type is still in the model, Paragon refuses and tells you how many instances to delete first. The type file is not removed, and the other copies stay in the model.

Reference meshes

A reference mesh is scenery for the visualizer, usually an OBJ of the architecture. Meshes are attached to a zone. They help you line fixtures up with the real space. They do not output light.
