Fixture types

A fixture type is the template. Instances in the model are copies of that template, each with its own position.

Creating a type

From a zone’s menu, choose Create Fixture. Paragon asks which kind:

  • Custom — place points by hand, and nest other fixtures inside the type.
  • Strip — plot a few nodes into a line. Paragon generates the LEDs from a count, using stretch or a fixed pitch.

Types can be filed into folders in the fixture list. Drag a type onto a folder to move it. Right-click a folder to rename or delete it. A folder cannot be deleted while any type inside it still has instances in the model.

Strips

A strip is defined by nodes, an LED count, and a distribution mode.

  • Stretch spreads the LEDs evenly between the nodes.
  • Pitch spaces LEDs by a distance you set. Pitch is entered in the project’s length unit.

Changing the LED count, mode, or pitch updates instances of that strip type. Focus the field and leave it before the change is written, so a stray click does not rewrite the strip.

Editing points

Open a type to edit its points or nodes in the visualizer. Custom fixtures store each point. Strip fixtures store the nodes; the LEDs are generated.

Render to Custom bakes one strip instance into a new custom type. You name that type. The new type has one editable point per LED, and it no longer has stretch, pitch, or an LED count. Only the instance you rendered changes type.

Adding an instance

Right-click a zone and choose Add Fixture, or use the Add Fixture button, and pick a type. The new instance appears in that zone. Duplicate an existing instance when you want the same pose copied.
