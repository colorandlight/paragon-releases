Projects and shows

A project is the installation. A show is one programmed lookbook that plays on that installation. One project can hold more than one show.

Projects

Use Project → New Project or Project → Open Project. Project → Open Project In Finder reveals the project folder. Project → Project Settings… holds settings for the open project. The Project menu also shows the current revision number.

The model is stored in the project as model.pgm. Fixture type definitions live in the project’s fixtures folder as .pgf files. Model → Save Model writes fixture geometry. It does not save the show.

Shows

Shows are .pgs files in the project’s shows folder.

  • Show → Save Show writes scenes, canvases, palettes, and the rest of the programmed show.
  • Show → Open Show loads another show from the same project.
  • Show → Set As Default makes the current show the one that opens with the project.

Save the model when you move fixtures. Save the show when you change scenes, colors, or playback.
