Remote

Remote lets another device join the show so an operator is not stuck at the Mac running Paragon.

Setup

Open Remote Settings from the Remote menu. The Mac running Paragon is the host. A remote client connects to that host and is trusted before it can control the show.

The Remote menu lists trusted devices. A status dot shows whether each one is connected.

What it is for

Use remote for a phone or another computer at the installation: picking scenes, riding levels, or checking that the show is running, while the Mac stays with the output hardware.
