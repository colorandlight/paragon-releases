Live control

These panels sit on the Show menu. They change a running show without editing the scene by hand.

MIDI

Show → Edit Midi listens to a MIDI device and routes notes or controllers to parameters. Use it for a control surface or a show-control message.

Audio

Show → Edit Audio takes a level from an audio input. Map that level onto brightness, speed, or any other parameter that should follow sound.

Triggers

Show → Edit Triggers fires an action when an input matches: a MIDI note, a button, or another trigger source. Triggers are for discrete events, such as advancing a scene.

Modulators

Show → Edit Modulators builds continuous motion on top of a parameter. Periodic modulators repeat a shape. Timer modulators run for a set duration. A modulator is how a static level becomes a pulse, a fade, or a sweep without a new scene.

Schedule

Show → Edit Schedule runs show changes on a clock. Use it for installations that should start, switch scenes, or stop without an operator.
