Install Paragon

Paragon runs on macOS. The download is a signed and notarized disk image.

Download

  1. Open paragon.colorandlight.art and download the latest disk image.
  2. Open the disk image and drag Paragon into Applications.
  3. Launch Paragon from Applications.

The first launch may ask macOS to confirm the app. It is Developer ID signed. If Gatekeeper still blocks it, open System Settings → Privacy & Security and choose Open.

License

An unlicensed copy runs the visualizer only. LED output stays off until the Mac is licensed. Open Paragon → License… to enter a license.

Updates

Paragon checks for updates in the background and never installs one without asking. Use Paragon → Check for Updates… to look manually. Installing an update quits the app, so do not update during a live show.
