Color and canvases

Color palettes are reusable sets of colors. Canvases decide which fixtures receive a look, and how that look is mapped onto their points.

Color palettes

Open Show → Edit Color Palettes. A palette is a strip of colors a scene can target. Duplicate a palette when you want a variation without editing the original. Assign palettes from the scene that uses them.

Canvases

A canvas is a surface made of fixtures. It can be a whole zone, a chosen set of fixtures, or a custom region. Scenes paint onto canvases rather than onto every LED in the project.

In the model’s Canvases tab you create and edit canvases. A custom canvas can be promoted into the library so other scenes can reuse it. While editing a canvas you can add or remove fixtures from the visualizer.

Canvas data is stored with the show. Model → Save Model does not save canvases. Use Show → Save Show.
