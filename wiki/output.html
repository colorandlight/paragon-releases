Output

Output is the path from a point in the model to a channel on a controller. Without a mapping, the visualizer still runs. The LEDs in the room do not.

License

LED output is disabled on an unlicensed Mac. The visualizer still works. License the Mac from Paragon → License… before a show that has to hit hardware.

Devices and universes

Open Output → Edit Outputs. Add the controllers for the installation and the universes they listen on. The universe editor is where a controller’s channel layout is set.

Fixture mapping

Map a fixture instance onto a device so each of its points lands on a channel. Mapping follows the fixture’s point order. If you delete a mapped fixture, Paragon asks you to remove the mapping first so a channel is not left pointing at a fixture that no longer exists.

Output → Save Outputs writes the mapping into the project. Save it separately from the model and the show.
