Paragon wiki

Paragon is Color+Light’s lighting control app for macOS. A project holds the physical model of a space. A show holds the scenes, colors, and playback that run on that model. Output sends the result to LED controllers.

This wiki covers the features in the current app. Screenshot slots are left empty so images can be dropped in later. Put a PNG in wiki/images/ using the filename under each slot, and it will appear on the next deploy.

How the app is organized

  • Projects and shows — the files you open, save, and take to a venue.
  • Model — zones, groups, and the fixtures placed in space.
  • Fixtures — fixture types, strips, custom fixtures, and editing points.
  • Visualizer — the 3D view used to place and check the rig.
  • Mixer and scenes — playback, banks, and the scene editor.
  • Color and canvases — palettes and how color is painted onto fixtures.
  • Output — devices, universes, and mapping LEDs to hardware.
  • Live control — MIDI, audio, triggers, modulators, and the schedule.
  • Remote — running a show from another device.

A typical workflow

  1. Create or open a project.
  2. Build zones and place fixtures in the model. Check them in the visualizer.
  3. Map fixtures to output devices when the hardware is ready.
  4. Build scenes and palettes in a show, then save the show.
  5. Play the show from the mixer. Use MIDI, audio, triggers, or remote when the installation needs them.
